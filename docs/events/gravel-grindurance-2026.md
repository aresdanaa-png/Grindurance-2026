- Peserta 150/200 km **wajib menempuh minimal 30 km mandiri** sebelum registrasi di Start Point.
- Waktu ideal bersepeda prolog: sekitar 03:00–05:00 WIB.
- Validasi lewat **rekaman GPS** peserta saat scrutineering pagi hari.
- Gagal memenuhi jarak atau terlambat → **tidak boleh start**.

## 4. Rute & Medan

- Dari Cibubur ke arah timur/tenggara: **Cileungsi → Jonggol (Cimenyan)** → persawahan → tanjakan menengah di **Sukamakmur–Cariu**.

- Variasi medan: aspal mulus → tanah perkebunan → aspal kelupas.

## 5. Cuaca Desember (Musim Hujan)

Ekspektasi: **lumpur tebal, licin, risiko hipotermia**. Panitia wajib menerbitkan **Athlete Guide**.

### Perlengkapan sepeda
- Tekanan ban turun **2–3 psi** dari kondisi kering (jangan di bawah batas minimum pabrikan → risiko pinch flat).
- Ban lebar **minimal 35–40 mm**; tread semi-slick/file tread atau blok terbuka (hindari lumpur menyumbat).
- **Wet lube wajib** untuk 150 km & 200 km (dry lube cepat hilang).
- Bawa **master link** cadangan.
- Mudguard/fender sangat dianjurkan.
- **Lampu wajib**: putih di depan, merah berkedip di belakang.

### Teknik berkendara
- Hindari rem depan mendadak di tanah basah/lumut (risiko front-wheel washout).
- Geser berat badan sedikit ke belakang.
- Jaga cadence moderat dan stabil agar tidak wheel slip.

### Pakaian
- Jaket waterproof-breathable (mis. membran GoreTex) untuk cegah hipotermia.

## 6. Checkpoint, Tracking & Pitstop

### Smart Geofencing Checkpoint
- Tidak ada stempel/kertas manual.
- Aplikasi **RaceRoute.id** wajib untuk kategori **120, 150, 200 km**.
- Ponsel menjalankan **Traccar Client**; saat masuk radius geofence (contoh **50 m** dari pusat pos), server mencatat timestamp otomatis.
- **Offline buffering**: data disimpan lokal saat tidak ada sinyal, dikirim otomatis saat konektivitas kembali.
- Peta pantau publik: **Live Tracking Board**.

### Format Mandiri (Self-Supported)
- Peserta bebas mengatur ritme istirahat dan nutrisi di sepanjang rute secara mandiri.
- Dilarang keras menerima pengawalan mobil support pribadi atau bantuan feeding terlarang.

## 7. Virtual Ride Nasional

Peserta di luar Jabodetabek (bahkan luar negeri) ikut di hari yang sama.

### Pembagian peran
| Pihak | Tanggung jawab |
|---|---|
| **Panitia Nasional (Jakarta)** | Clearing house: standar mutu, regulasi, e-sertifikat, distribusi medali |
| **Regional/Chapter GX-ID** | Titik temu (Tikum) lokal, kurasi rute lokal dengan kesulitan/jarak/elevasi setara |

### Arsitektur validasi otomatis

```
Komoot (rencana rute, .gpx)
        │
        ▼
Peserta gowes outdoor (Garmin/Wahoo/HP)
        │  upload aktivitas
        ▼
Strava ──(Webhook Events API)──► Back-end GX-ID
                                      │
                    ┌─────────────────┼──────────────────┐
                    ▼                 ▼                  ▼
          Validasi jarak,      Tolak aktivitas      Generate e-Certificate
          elevasi, avg speed   indoor/virtual       → kirim ke email
                               (smart trainer,             │
                               Zwift, dll)                 ▼
                                                  Rekap alamat → DHS Logistik
                                                  → kirim Metal Medal
```

### Langkah-langkah
1. **Rute**: dirancang & diunduh dari Komoot (.gpx), dipakai untuk turn-by-turn di head unit.
2. **Webhook Strava**: server menerima notifikasi push real-time saat peserta upload aktivitas.
3. **Filter**: cek jarak final, total elevation gain, kecepatan rata-rata minimal.
4. **Anti-curang**: aktivitas indoor/virtual trainer **ditolak**; hanya GPS outdoor valid.
5. **Output**: e-Certificate otomatis ke email + data pengiriman medali ke DHS Logistik.

## 11. Spesifikasi Siap-Pakai untuk Developer

Cocok ditempel sebagai konteks ke AI coding tool kalau mau membangun sistem pendukung event (registrasi, validasi, dashboard).

### Konfigurasi kategori

```json
{
  "categories": [
    { "id": "60",  "km": 60,  "type": "fun",   "cot_hours": [6, 7],   "start": "07:00", "tracking_required": false, "prologue_km": 0,  "pitstop_cp": 6 },
    { "id": "80",  "km": 80,  "type": "fun",   "cot_hours": [8, 9],   "start": "07:00", "tracking_required": false, "prologue_km": 0,  "pitstop_cp": 6 },
    { "id": "120", "km": 120, "type": "race",  "cot_hours": [10, 11],  "start": "06:00", "tracking_required": true,  "prologue_km": 0,  "pitstop_cp": 4 },
    { "id": "150", "km": 150, "type": "cross", "cot_hours": [14, 15], "start": "05:30", "tracking_required": true,  "prologue_km": 30, "pitstop_cp": 4 },
    { "id": "200", "km": 200, "type": "ultra", "cot_hours": [17, 19], "start": "05:30", "tracking_required": true,  "prologue_km": 30, "pitstop_cp": 4 }
  ],
  "pitstop_min_minutes": 30,
  "pitstop_penalty_multiplier": 3.0,
  "geofence_radius_m": 50
}
```

### Aturan validasi

```
Prolog (150/200 km):
  - GPS track sebelum registrasi harus >= 30 km
  - Jika kurang atau tiba terlambat → DENY START

Pitstop:
  - dwell_time di CP wajib >= 30 menit
  - jika kurang → penalti waktu (multiplier 300%)

Virtual Ride (via Strava webhook):
  - Tolak jika activity bertipe virtual/indoor/trainer
  - Terima jika: distance >= minimum, elevation_gain >= minimum, avg_speed >= minimum
  - Terima → generate e-certificate + push alamat ke vendor logistik

Tracking (RaceRoute.id + Traccar):
  - Masuk radius geofence → catat timestamp
  - Data offline di-cache lokal, kirim saat online
```

### Ide modul sistem

| Modul | Fungsi |
|---|---|
| Registrasi | Pilih kategori, add-on asuransi, upload GPS prolog |
| Scrutineering | Validasi prolog 30 km dari file GPS |
| Live Tracking | Peta publik + status CP per peserta |
| Webhook Strava | Endpoint penerima event aktivitas |
| Validator | Cek jarak/elevasi/kecepatan, filter indoor |
| Sertifikat | Generate PDF/gambar + kirim email |
| Logistik | Ekspor data alamat finisher untuk kurir |
| Dashboard Regional | Pantau Tikum & peserta tiap Chapter |

> Catatan: bagian 11 adalah **turunan/saran implementasi** dari isi dokumen, bukan bagian dari dokumen asli. Nilai minimum untuk jarak, elevasi, dan kecepatan virtual belum ditetapkan di dokumen sumber.
